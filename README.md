### 🛠️ Набор Интерактивных Утилит (Vibe Utility Suite v5.0)

- **⏱️ Pomodoro Focus Timer (25 мин)**: Таймер фокусировки с возможностью паузы, сброса и звуковым оповещением окончания сессии через Web Audio API.
- **🧮 Code Complexity & Vibe Calculator**: Динамический математический расчёт уровня вайба и производительности на основе написанных строк кода, выпитого кофе и багов.
- **📝 Vibe Scratchpad (Автосохранение)**: Блокнот идей и заметок с мгновенным автосохранением в `LocalStorage` браузера.
- **🗺️ CS Roadmap & Tech Radar 2026**: Наглядный таймлайн развития и технологический радар 2026 года.
- **🎮 CS Vibe Trivia Quiz**: Интерактивная викторина по Computer Science с подсчётом очков.
